# SecureCloud Project Scope

## Problem

Infrastructure configured manually can become inconsistent and
may contain security mistakes.

## Approach

SecureCloud will use Terraform code, security checks, automated
validation, and documentation to demonstrate a safer infrastructure
workflow.

## Initial Constraints

- Use free tools wherever possible.
- Do not deploy paid cloud resources.
- Review commands and infrastructure plans before execution.
- Do not store credentials or sensitive state in Git.
- Clearly distinguish local tests from real cloud deployment.

## Planned Capabilities

1. Reusable Terraform configuration.
2. Cloud network and access-control design.
3. Security scanning and policy checks.
4. Automated validation through GitHub Actions.
5. Documented test results and known limitations.

## Current Status

The project workspace is being prepared. Infrastructure has not
been deployed to AWS.
