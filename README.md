# SecureCloud

A zero-cost Terraform and cloud security portfolio project.

## Project Goal

SecureCloud demonstrates how to organize infrastructure as code,
check infrastructure configurations for security issues, and automate
quality and security checks.

## Learning Objectives

- Write and organize Terraform configurations.
- Understand cloud networking and access control.
- Detect insecure infrastructure configurations.
- Automate validation and security checks.
- Document architecture, testing, and security decisions.

## Cost Policy

This project is designed to use free local tools and free development
workflows. No paid AWS resources will be created without explicit
cost review and approval.

## Project Status

Phase 1: Development environment and project structure.

Cloud deployment has not been performed.

## Repository Structure

- `docs/` - project documentation
- `terraform/` - Terraform configurations and modules
- `policies/` - security policies and checks
- `tests/` - project tests
- `scripts/` - helper scripts
- `.github/workflows/` - automated GitHub workflows

## Security

Never commit cloud credentials, API keys, passwords, or sensitive
Terraform state files to this repository.
